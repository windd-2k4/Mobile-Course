# Tuần 3: Flexbox & Thiết Kế Giao Diện Di Động (Phần 1)

## 🎯 Mục tiêu
- Nắm vững kiến trúc Flexbox trong React Native: `flexDirection`, `justifyContent`, `alignItems`, `flexWrap`, `position: absolute`.
- Thiết kế giao diện thực tế cho ứng dụng F&B "Aroma Coffee & Bakery".

## 📝 Danh sách bài tập:
1. **CoffeeHeader**: Header điều hướng với avatar, thông tin người dùng và chuông thông báo (Flexbox Row + Space-between).
2. **PromoBanner**: Khối banner khuyến mãi nổi bật kết hợp hình ảnh, thẻ tag ưu đãi và nút kêu gọi hành động (CTA).
3. **CategoryChips**: Thanh danh mục thức uống dạng cuộn ngang và chip lọc linh hoạt.
4. **BeverageRowCard**: Card sản phẩm dạng hàng ngang (Thumbnail ảnh trái, thông tin giá & đánh giá bên phải).
5. **BeverageGrid**: Lưới sản phẩm 2 cột (`width: 48%`) tích hợp Badge giảm giá `position: absolute`.

## 🚀 Cách chạy ứng dụng
```bash
cd coffee_shop_layout
npm install
npx expo start
```
