# Tuần 10: Quản Lý State Toàn Cục Với Redux Toolkit & React-Redux

## 🎯 Mục tiêu
- Thiết lập kiến trúc Redux Toolkit hiện đại: `configureStore`, `createSlice`, `PayloadAction`.
- Quản lý trạng thái mua sắm toàn cục: Giỏ hàng, thêm sản phẩm, tăng/giảm số lượng và tính tiền tự động.
- Tạo Typed Hooks: `useAppDispatch` và `useAppSelector` đảm bảo type-safety hoàn hảo.

## 🚀 Cách chạy ứng dụng
```bash
cd redux-shopping-cart
npm install
npx expo start
```
