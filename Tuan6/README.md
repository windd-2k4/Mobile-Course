# Tuần 6: React Navigation Chuyên Sâu (FreshBite Delivery)

## 🎯 Mục tiêu
- Thành thạo các bộ điều hướng phổ biến nhất của React Navigation:
  - **Native Stack Navigator**: Điều hướng phân cấp nhiều cấp màn hình và truyền nhận tham số 2 chiều (`route.params`).
  - **Bottom Tab Navigator**: Điều hướng qua thanh công cụ tab dưới đáy màn hình.
  - **Drawer Navigator**: Menu trượt từ cạnh bên (Side Drawer) tích hợp màn hình Cài đặt với Switch.
- Sử dụng TypeScript types chuẩn xác: `NativeStackScreenProps`, `BottomTabScreenProps`, `CompositeScreenProps`.

## 📁 Cấu trúc thư mục:
- `freshbite_navigation/App.tsx`: Triển khai toàn bộ bài tập điều hướng.
- `freshbite_navigation/mockapi-sample.json`: Dữ liệu MockAPI mẫu cho món ăn & nhà hàng.

## 🚀 Cách chạy ứng dụng
```bash
cd FreshBite_Navigation_Exercises/freshbite_navigation
npm install
npx expo start
```
