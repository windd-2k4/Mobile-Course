# Tuần 9: Tổ Chức Dữ Liệu Phức Tạp & SectionList (EventMaster Booking)

## 🎯 Mục tiêu
- Thành thạo component `SectionList` để hiển thị danh sách dữ liệu có phân nhóm theo tiêu chí (Nhóm theo thành phố).
- Thiết kế các hàm tiện ích xử lý dữ liệu: `groupByCity`, `formatVND`.
- Tính toán và cập nhật trạng thái số lượng chỗ trống và phản hồi thông báo tương tác.

## 🚀 Cách chạy ứng dụng
```bash
cd event_booking
npm install
npx expo start
```
