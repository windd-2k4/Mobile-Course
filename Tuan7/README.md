# Tuần 7: Tích Hợp REST API Với MockAPI (SoundWave Podcast)

## 🎯 Mục tiêu
- Kết nối và tiêu thụ REST API từ MockAPI bằng `fetch` và `useEffect`.
- Tối ưu hiệu năng danh sách với `FlatList`, `ActivityIndicator` và `RefreshControl`.
- Lọc dữ liệu thông minh với `useMemo` và quản lý trạng thái Bookmark / Xóa trực tiếp.

## 🚀 Cách chạy ứng dụng
```bash
cd podcast_discovery
npm install
npx expo start
```
