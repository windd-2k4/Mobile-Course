# Tuần 8: Ứng Dụng CRUD Hoàn Chỉnh Với REST API (GearZone Store)

## 🎯 Mục tiêu
- Xây dựng trọn vẹn luồng CRUD (Create - Read - Update - Delete):
  - **Create**: Mở Modal nhập dữ liệu và gửi yêu cầu tạo mới sản phẩm.
  - **Read**: Tải và hiển thị danh sách phụ kiện với bộ lọc và tìm kiếm nhanh.
  - **Update**: Điền thông tin cũ vào Modal, cập nhật trường dữ liệu và lưu lại.
  - **Delete**: Hộp thoại xác nhận Alert.alert và xóa sản phẩm tức thì.

## 🚀 Cách chạy ứng dụng
```bash
cd gear_store
npm install
npx expo start
```
